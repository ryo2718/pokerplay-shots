# pokerplay-shots

ポーカー塾 (pokerplay の 1 人モード) の 全画面の スクリーンショット一式。別の AI に UI チェックを してもらうための 置き場。

- 撮影した 端末の 幅: **360** (高さ 760、 deviceScaleFactor 2 → 画像は 720 × 1520 の webp)。 「今回の直し」の 「直したあとの確認」 だけ 高さ 667 (720 × 1334) の 画像も ある
- 撮影日: **2026-10-30 夜** (22 時台。 UI の 大きな 修正 (カード・下部シート・用語タグ など) の あとの 撮り直し。 前の 版 (14 時台) は git の 履歴に ある)
- 中身は 確認環境の 一覧ページ (`/shots-b7a329262a/`) と 同じ: `index.html` (一覧ページ)、 `img/` (画像)、 `manifest.json` (画像の 一覧)

## manifest.json

画像 1 枚ごとに 1 行。並びは 一覧ページと 同じ (今回の直し → 体験 → 初級 言葉 → 7級 戦術 → コラム → 6級 → テスト)。

| 項目 | 中身 | 例 |
|---|---|---|
| section | 大きな 区分 | `6級 参加ハンドの選定` / `テスト` / `今回の直し` |
| chapter | 章の タイトル | `5. やりがちなミスと4原則` |
| label | ページの キャプション | `12・答えたあと` |
| path | 画像の パス | `img/pick/05/12b.webp` |

キャプションの 読み方: 番号 = 章の 手順 (`?step=N`)、 `・答えたあと` = クイズに 正解を 選んだ あと、 `・カードを 選んだところ` = 役になるカード・アウツ・7 枚から 5 枚の 問題で 正解の カードを タップしたところ (決定の 前)、 `・次へ N` = 解説の 中の 次の 段 (範囲 → 判定式)、 `・実演の途中 N` = 自動で 進む 実演の 途中。 テストは 問題が 毎回 ちがう。

## 撮り方

pokerplay の `scripts/solo/allshots.mjs` (撮る) → `scripts/solo/mkgallery.py` (一覧ページと manifest.json)。 画面を 直して 撮り直したら この リポジトリに 上書きで コミットする。

## 今回の直し の 「直したあとの確認 (10/30 夜)」

`request.md` §4 の 5 の 状態。 ポット 3 桁・4 桁、 6 人全員が チップを 出している、 テストの 「答えたあと」 で 解説が 一番 長い 問題、 高さ 667 (iPhone SE) の 画面。 台本に 4 桁の ポットは 無いので、 `[額を 10 倍に 書きかえた 表示]` `[額を 100 倍に 書きかえた 表示]` `[ポットの 数字だけ 書きかえた 表示]` と 書いてある 画像は 見た目の 確認用に 数字だけ 変えて 表示した もの (台本・アプリは 変えていない)。 `(台本のまま)` は 実際の 画面。 テストの 「準備中」 (フロップ 3 つ・数学テスト) は 問題が まだ 無いので 画像なし。
