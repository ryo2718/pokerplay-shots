# pokerplay-shots

ポーカー塾 (pokerplay の 1 人モード) の 全画面の スクリーンショット一式。別の AI に UI チェックを してもらうための 置き場。

- 撮影した 端末の 幅: **360** (高さ 760、 deviceScaleFactor 2 → 画像は 720 × 1520 の webp)
- 撮影日: **2026-10-30**
- 中身は 確認環境の 一覧ページ (`/shots-b7a329262a/`) と 同じ: `index.html` (一覧ページ)、 `img/` (画像)、 `manifest.json` (画像の 一覧)

## manifest.json

画像 1 枚ごとに 1 行。並びは 一覧ページと 同じ (今回の直し → 体験 → 初級 言葉 → 7級 戦術 → コラム → 6級 → テスト)。

| 項目 | 中身 | 例 |
|---|---|---|
| section | 大きな 区分 | `6級 参加ハンドの選定` / `テスト` / `今回の直し` |
| chapter | 章の タイトル | `5. やりがちなミスと4原則` |
| label | ページの キャプション | `12・答えたあと` |
| path | 画像の パス | `img/pick/05/12b.webp` |

キャプションの 読み方: 番号 = 章の 手順 (`?step=N`)、 `・答えたあと` = クイズに 正解を 選んだ あと、 `・次へ N` = 解説の 中の 次の 段 (範囲 → 判定式)、 `・実演の途中 N` = 自動で 進む 実演の 途中。 テストは 問題が 毎回 ちがう。

## 撮り方

pokerplay の `scripts/solo/allshots.mjs` (撮る) → `scripts/solo/mkgallery.py` (一覧ページと manifest.json)。 画面を 直して 撮り直したら この リポジトリに 上書きで コミットする。
